How Masar works

A directory that does not sell you.

Most course directories are lead-generation businesses wearing an editorial coat. This one is built the other way round.

If a listing is here, it is because it belongs in the index — not because someone paid for the position.
— The editorial policy, in one sentence

  1. Search without an account

    Every filter, every listing and every fee is visible without signing up for anything.

  2. Compare on what matters

    Fee, teaching days, format, language of instruction and start date — on every card, in the same place, so comparison takes seconds.

  3. Save a shortlist

    Keep candidates in one list as you browse. It stays in your own browser; we never see it.

  4. Go straight to the school

    Enquiries go to the institution running the programme. Your details are not resold.
