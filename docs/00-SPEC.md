# Spec — EMFT Website

_Last updated: 2026-08-04_

## What this is
The public marketing website for EMFT: company profile, programs, coaching,
e-learning, assessments, speakers, case studies, and contact — plus legal
pages (privacy, terms).

## Who it's for
Prospective clients and partners evaluating EMFT's offerings; search engines
(the site is SEO-optimized with sitemap, robots.txt, and per-page metadata).

## What "done" means for any change
- The changed pages render correctly on desktop and mobile.
- Navigation and internal links all work.
- SEO assets (sitemap, meta tags) reflect the change.
- The change is deployed via GitHub Pages and verified live.
- The phase log (`03-PHASE-LOG.md`) is updated.

## Out of scope (today)
No user accounts, no payments, no database. If any of these become needed,
that is a new project phase requiring a spec update and an architecture
decision record first.
